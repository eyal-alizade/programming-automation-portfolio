# Publishing this portfolio

The `WORK` directory is the public portfolio source. The neighboring `business-kit` directory contains private operating materials and is not part of this repository.

Suggested repository name: `programming-automation-portfolio`.

1. Create or sign in to the intended GitHub account. Use the account's actual username when configuring a remote.
2. Create a new public repository. If uploading this existing source, do not add a second README during creation.
3. Upload the contents of `WORK`, including `.github`, `.gitignore`, the project folders, and the root README. Do not upload a virtual environment, runtime database, real `.env`, or generated demo state.
4. Check the rendered root README and each featured project's demo instructions. The included CI workflow will run after publication; its result must be checked on GitHub before describing it as passed there.
5. Keep the contact address as `mr.pitronot@gmail.com` unless a replacement address is actually created.

Each project can also become a separate repository later. The root README uses relative links and is ready for a single portfolio repository first.

No software license grant has been added. This is a portfolio publication package; choosing a reuse license is a separate decision.

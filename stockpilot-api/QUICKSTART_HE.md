# StockPilot — ניהול מלאי והזמנות דרך API

פרויקט תיק עבודות אישי של אייל אליזאדה. הוא מדגים מערכת עסקית עם מוצרים, יומן תנועות מלאי, הזמנת כמה מוצרים באותה פעולה, ביטול ושחזור מלאי ומניעת ביצוע כפול של בקשה. הדוגמאות סינתטיות בלבד; זה אינו פרויקט לקוח או שירות שפורסם.

דרוש Python 3.11 ומעלה. מתוך תיקיית הפרויקט:

```sh
python -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python demo.py --output-dir demo-output
.venv/bin/python -m unittest discover -s tests -v
```

ב־Windows משתמשים ב־`.venv\Scripts\python.exe` במקום `.venv/bin/python`.

ההדגמה מפעילה בקשות מול היישום עצמו, בתוך התהליך, ללא שרת HTTP או שירות חיצוני. היא יוצרת מסד נתונים זמני ומפתח זמני, ובודקת שהזמנה מורידה מלאי, ניסיון הזמנה מעבר למלאי נדחה, שליחה חוזרת אינה יוצרת הזמנה כפולה וביטול חוזר מחזיר מלאי רק פעם אחת.

ב־`demo-output` מתקבלים דוח תוצאות, קובצי CSV סינתטיים ומפרט OpenAPI. יש לבחור תיקיית פלט חדשה לכל הרצה. מפתח הגישה אינו נכתב לפלט.

להפעלת שרת מקומי:

```sh
export STOCKPILOT_API_KEY="$(.venv/bin/python -c 'import secrets; print(secrets.token_urlsafe(32))')"
.venv/bin/python -m uvicorn stockpilot:create_app --factory --host 127.0.0.1 --port 8000
```

אפשר לפתוח את [תיעוד ה־API המקומי](http://127.0.0.1:8000/docs), לבחור Authorize ולהכניס את המפתח. אל תשתף את המפתח או מסד נתונים המכיל מידע אמיתי. הוראות PowerShell מופיעות ב־README.

בקשות יצירת הזמנה ושינוי מלאי דורשות כותרת `Idempotency-Key`: שליחה חוזרת עם אותו מפתח ואותו גוף בקשה תחזיר את התוצאה המקורית בלי לבצע שוב. מחיר נשמר באגורות וכמות ביחידות שלמות. מחיקת מוצר משביתה אותו ושומרת את ההיסטוריה.

זהו Backend לדוגמה, ללא תשלומים, משתמשים והרשאות נפרדות או הבטחת מוכנות לייצור. התוכנה לא פורסמה. פירוט הממשקים, התנהגות הבקשות החוזרות והמגבלות נמצא ב־README באנגלית.

# דסקבאדי 🐾 — התחלה מהירה

פרויקט תיק עבודות של **אייל אליזאדה / Eyal Alizade**. ההדגמה משתמשת בנתונים מלאכותיים; היא אינה עבודה עבור לקוח אמיתי.

צריך Python בגרסה 3.11 ומעלה. אין ספריות חיצוניות להתקין.

מתוך תיקיית הפרויקט:

```bash
python -m deskbuddy demo
python -m unittest discover -s tests -v
```

ההדגמה עוברת דרך פתיחת בקשה, שמירת טיוטה, הפעלה מחדש, מניעת כפילות וסגירה בידי מנהל. אין צורך בחשבון Telegram, בטוקן או בחיבור לרשת.

לשיחה מקומית שבה אפשר לנסות בעצמך:

```bash
python -m deskbuddy simulate
```

- מתחילים כלקוח הדגמה שמספרו `1001`.
- כותבים `/new`, עונים על השאלות וכותבים `שלח` לאישור.
- `:as 9001` מעביר למנהל ההדגמה; `/queue` מציג את התור ו־`/ticket 1` את הפרטים.
- `/close 1 הטיפול בהדגמה הושלם` סוגר את הבקשה ושולח עדכון ללקוח המלאכותי.
- `:as 1001` חוזר ללקוח; `/status` מציג את המצב שלו בלבד.
- `:quit` מסיים. החלפת הזהות קיימת רק בסימולטור המקומי.

לשמירת שיחת הסימולטור בין הפעלות:

```bash
python -m deskbuddy simulate --db .deskbuddy/offline.sqlite3
```

מצב Telegram אמיתי מופעל רק בפקודת `poll` עם משתני סביבה שהגדרת בעצמך. בהדגמה הזו לא נפתח בוט אמיתי ולא נשלחה הודעה. פרטי ההפעלה והגבולות מופיעים ב־README באנגלית. מסד נתונים של הסימולטור לא יכול להתחבר בטעות לבוט אמיתי.

הבוט מבוסס על כללים ושאלות מסודרות, ואינו משתמש ב־AI. אין סליקה, שליחת פרסום המוני או הבטחת מוכנות להפעלה מסחרית. פרטי קשר נשמרים מקומית ב־SQLite ללא הצפנה ברמת היישום.

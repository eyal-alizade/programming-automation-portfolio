# דסקבאדי — התחלה מהירה

צריך Python 3.11 ומעלה. מריצים מתוך תיקיית הפרויקט:

```bash
python -m deskbuddy web-demo --port 8812
```

פותחים [127.0.0.1:8812](http://127.0.0.1:8812), בוחרים **לקוח** ולוחצים על **בקשה חדשה**. עונים על השאלות ומאשרים שליחה.

לאחר מכן עוברים ל־**מנהל**. אפשר לפתוח את פרטי הבקשה ולסגור אותה. חזרה לצד הלקוח מציגה את עדכון הסגירה.

זה דמו מקומי עם נתונים מלאכותיים. הוא מפעיל את קוד הבוט ואת מסד הנתונים בפועל, בלי להתחבר ל־Telegram. השיחות נשמרות בזמן שהתהליך פועל ונמחקות כשעוצרים אותו.

לעצירה לוחצים Ctrl+C במסוף. אין צורך בטוקן או בחשבון.

אפשר גם לנסות דרך המסוף ולבדוק את הקוד:

```bash
python -m deskbuddy demo
python -m deskbuddy simulate
python -m unittest discover -s tests -v
```

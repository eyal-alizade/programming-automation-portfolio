# איחוד קובצי מכירות — התחלה מהירה

פרויקט תיק עבודות של **אייל אליזאדה / Eyal Alizade**. כל קובצי הדוגמה מלאכותיים.

צריך Python בגרסה 3.11 ומעלה. אין תלות בספריות חיצוניות.

```bash
python -m csv_report_builder samples/sales-a.csv samples/sales-b.csv --output demo-output --currency ILS
python -m unittest discover -s tests -v
```

התוצאה הצפויה בדוגמה: שש רשומות, כפילות מדויקת אחת שהוסרה, חמש רשומות בפלט וסכום של **185.10 ₪**.

בתיקיית הפלט יהיו קובץ מאוחד, סיכום לפי פריט, דוח JSON ודוח טקסט. הקלט המקורי אינו משתנה. צריך לבחור תיקיית פלט חדשה; החלפה מכוונת של ארבעת קובצי הדוח דורשת `--overwrite`.

העמודות הנדרשות הן `date,item,quantity,unit_price`. תאריך בפורמט `YYYY-MM-DD`, כמות שלמה וחיובית, ומחיר לא שלילי עם עד שתי ספרות אחרי הנקודה. אפשר להשתמש גם בכותרות החלופיות שמופיעות ב־README. עמודות נוספות נשמרות.

הכלי תומך בקבצים מופרדים בפסיק, נקודה־פסיק, טאב או קו אנכי, עם מירכאות ו־UTF-8/BOM. רשומה לא תקינה עוצרת את הפעולה לפני פרסום הדוחות. סכומים מחושבים ב־Decimal ללא חישובי כסף בנקודה צפה.

כפילות היא רשומה שבה כל הערכים זהים תחת שמות העמודות המנורמלים. אם רשומות זהות הן מכירות נפרדות ואמיתיות, הוסיפו `--keep-duplicates`. הכלי אינו יודע לזהות הזמנה לפי כוונת המשתמש.

טקסט שעלול להתפרש כנוסחה בגיליון מקבל גרש בתחילתו כדי לשמור אותו כטקסט. כל קובצי הקלט חייבים להיות באותו מטבע; `--currency` רק מסמן אותו ואינו ממיר מטבעות.

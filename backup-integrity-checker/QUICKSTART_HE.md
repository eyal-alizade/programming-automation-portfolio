# גיבוי ובדיקת קבצים

יוצרים דוגמה של שלושה קבצים, מגבים ובודקים שהגיבוי תואם למקור:

```sh
python backup_checker.py demo --output-dir demo-output
```

נדרש Python 3.11 ומעלה. תיקיית הפלט צריכה להיות חדשה.
התוצאה התקינה כוללת `status: ok` ו־`source_matches: true`.

להוראות לגיבוי תיקייה משלך ולמגבלות הבדיקה: [README](README.md).
